# 생성 전 프롬프트 30초 점검 기법

특히 이미지 생성이나 긴 코딩 작업 등 시간과 토큰이 많이 드는 작업은 처음부터 바로 실행(생성) 버튼을 누르지 마십시오. "이 요청으로 만들어도 될까?"를 AI에게 먼저 물어보는 습관이 필요합니다.

## 점검 프롬프트 예시
> "내가 쓴 아래 이미지 생성 요청에 빠진 조건이 있는지 먼저 점검해 줘. 부족한 부분이 있으면 보완하고, 이미지 생성에 맞게 네가 다시 정리해 줘."
>
> [확인 기준: 사용 목적, 화면 비율, 넣을 정보, 배치, 분위기, 글자 양]
>
> 내 요청: [여기에 내가 쓴 엉성한 프롬프트 붙여넣기]

## 효과
처음부터 완벽한 프롬프트를 인간이 작성하려는 부담을 줄이고, `초안 작성 → AI의 점검 및 보완 → 최종 생성`이라는 훨씬 안정적인 파이프라인을 구축할 수 있습니다.

# Workflow Prompting (워크플로우 프롬프팅)

## 개념
긴 작업을 AI에게 한 번에 뭉뚱그려 맡기지 않고, '무엇을 만들지' 뿐만 아니라 **'어떤 순서로 만들지'** 단계와 산출물 단위로 쪼개어 연결해 주는 방식입니다.

## 일반적인 워크플로우 예시
`기준 정리(목적/대상) → 초안 작성 → 검토(오류/누락) → 재작성 → 최종 활용(대본/PPT 등)`

## 프롬프트 실습 예시
> "여행 계획을 아래 순서로 진행해 줘. 1단계가 끝나면 멈추고 내 확인을 받은 뒤 다음 단계로 넘어가.
> [순서: 여행 조건 정리 → 후보 비교 → 일정표 → 예산표 → 준비물 → 최종 점검]"

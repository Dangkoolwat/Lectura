# 자연스러운 한국어 체크리스트

AI가 다듬어준 글이라도 최종 판단과 점검은 사람이 해야 합니다. '좋은 다듬기'는 글을 새로 쓰는 것이 아니라 자연스럽게 정리하는 과정입니다.

## 1. 내용 유지 체크
- [ ] 사실, 날짜, 장소명, 이름, 금액, 수치를 바꾸지 않았는가?
- [ ] 원문에 없는 정보나 해석을 새로 추가하지 않았는가?
- [ ] 확인이 필요한 정보는 "확인 필요"로 남겼는가?
- [ ] 글의 목적과 분위기를 유지했는가?

## 2. 표현 다듬기 체크
- [ ] 과장된 표현이나 홍보문 같은 문장을 담백하게 줄였는가?
- [ ] 번역투와 어색한 표현("~를 통해", "~할 수 있다")을 다듬었는가?
- [ ] 영어식 완료·진행 표현("~해오고 있습니다")을 줄였는가?
- [ ] 반복되는 표현과 기계적인 나열("첫째, 둘째")을 줄였는가?

## 3. 읽기 흐름 체크
- [ ] 문장이 너무 길지 않고 읽기 편한가?
- [ ] 문단 흐름이 자연스럽게 이어지는가?
- [ ] 최종 독자에게 어색하지 않은 말투인가?
- [ ] 마지막으로 한 번 더 내가 직접 소리 내어 읽어 보았는가?

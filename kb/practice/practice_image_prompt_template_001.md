# 이미지 생성 프롬프트 6단계 조립법

이미지를 "예쁘게 만들어 줘"라고 막연히 지시하면 실패합니다. 아래 6가지 항목을 하나씩 채워서 조립하면 훨씬 안정적이고 의도에 맞는 인포그래픽/이미지가 생성됩니다.

## 1. 목적
무엇을 위한 이미지인지 먼저 선언합니다. (예: "모바일에서 보기 좋은 여행 요약 인포그래픽을 만들어 줘.")

## 2. 비율
화면 모양(비율)을 명확히 고정합니다. (예: "가로세로 비율을 9:16으로 설정해 줘.")

## 3. 핵심 정보
텍스트 문서의 내용을 다 넣지 말고 가장 중요한 키워드만 고릅니다. (예: "여행 제목, 핵심 일정, 방문지 이름만 포함해 줘.")

## 4. 레이아웃
정보를 어디에 배치할지 구조를 잡아줍니다. (예: "상단은 제목, 중간은 일정 카드, 하단은 맛집 요약을 배치해 줘.")

## 5. 톤(분위기)
그림의 분위기와 스타일을 구체적으로 묘사합니다. (예: "전체적으로 따뜻하고 부드러운 파스텔톤 일러스트 스타일로 그려줘.")

## 6. 텍스트 규칙
이미지 내 글자가 깨지거나 과도해지지 않도록 통제합니다. (예: "모든 텍스트는 매우 굵고 선명한 검은색 고딕체로 짧게 작성하고, 오타가 없는지 꼭 확인해.")

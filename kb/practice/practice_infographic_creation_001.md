# 한 장 인포그래픽 만들기 5요소

인포그래픽은 복잡한 텍스트 정보를 한눈에 보이도록 구조화하는 작업입니다. AI를 통해 인포그래픽 이미지를 생성할 때는 다음 5가지 요소를 고려해야 합니다.

1. **화면 비율**: 어디에 쓸 이미지인지 먼저 정합니다. (예: PPT 16:9, 모바일 9:16, 카드뉴스 1:1)
2. **정보 구조**: 무엇을 어떤 순서로 보여줄지 핵심만 고릅니다. (예: 제목 → 콘셉트 → 일정 → 예산)
3. **레이아웃**: 정보를 어떤 틀로 배치할지 정합니다. (예: 타임라인형, 카드형, 지도 배치형)
4. **시각 요소**: 정보를 쉽게 읽게 만드는 재료들을 지시합니다. (예: 아이콘, 번호 라벨, 강조 색상)
5. **표현 톤**: 이미지의 전체 분위기를 정합니다. (예: 깔끔한, 친근한, 모바일 콘텐츠 느낌)

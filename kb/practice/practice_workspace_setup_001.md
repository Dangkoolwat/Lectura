# 작업 공간 분리와 맞춤형 지침(Gems) 설정

AI와 대화할 때마다 새로운 채팅창을 열어 뒤죽박죽 섞이게 두지 말고, 특정한 목표나 주제를 가진 작업은 전용 작업 공간으로 분리해야 합니다.

## 핵심 이유
주제별로 작업 공간을 나누면 대화와 자료, 조건이 섞이는 것을 줄일 수 있어 AI가 더 일관성 있고 정확한 결과를 만듭니다.

## 플랫폼별 설정법
- **ChatGPT**: 좌측 메뉴에서 '프로젝트 만들기'를 통해 전용 공간을 설정할 수 있습니다.
- **Gemini**: 'Gems 관리자'에서 새 Gem을 생성하여 맞춤형 응답과 지침을 사전 설정할 수 있습니다.

> **💡 포인트**: 도구 이름(프로젝트, Gems, GPTs 등)은 달라도 핵심은 같습니다. 독립된 주제에는 독립된 작업 공간과 '글로벌 지침서'가 필요합니다.

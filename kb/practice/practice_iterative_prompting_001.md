# Iterative Prompting (반복 수정 프롬프팅)

## 개념
처음부터 완벽하고 긴 프롬프트를 작성하기보다, 첫 답변을 받은 뒤 조건을 하나씩 바꾸며 결과를 다듬어 나가는 방식입니다. 실무에서 가장 자주, 그리고 유용하게 쓰이는 기법입니다.

## 활용 상황
- 초안 글을 더 자연스럽게 다듬을 때
- 내용 추가, 삭제, 보완이 지속적으로 필요할 때
- 결과를 특정 형식(표, 목록 등)으로 다시 정렬할 때

## 프롬프트 실습 예시
초안을 뽑은 후, 다음과 같이 짧은 프롬프트로 대화하며 다듬습니다.
> "좋아. 이번에는 내용을 더 현실적으로 바꿔줘."
> "우리 가족(비전문가)에게 설명하기 쉽게 비유를 넣어줘."
> "최종 내용을 일정표 형식으로 다시 정리해 줘."

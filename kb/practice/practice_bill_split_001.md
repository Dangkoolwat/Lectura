# 모임 정산표 만들기

## 요약
모임 비용을 사람별로 공정하게 나누기 위해 정산표를 만드는 실습이다.  
총무가 자주 겪는 계산 스트레스를 줄이고, 결과를 표로 정리하는 연습에 적합하다.

## 강의 활용
- 생활 AI 실습 메뉴
- 모임 운영 실습
- 컴퓨터 표 만들기 연습

## 세부 내용
### 실습 목표
참석 여부, 부분 참석, 공용 지출을 반영해 사람별 부담금을 표로 정리한다.

### 준비물
- 모임 지출 내역
- 참석자 목록
- 부분 참석 정보
- 계산 결과를 적을 표

### 진행 순서
1. 지출 내역과 참석자 정보를 입력한다.
2. AI에게 정산표 초안을 요청한다.
3. 부분 참석이나 개인별 부담 항목을 반영한다.
4. 사람별 부담금을 표로 정리한다.
5. 총합이 맞는지 사람이 다시 확인한다.

### 결과물
- 사람별 정산표
- 총지출 합계 확인표
- 이체 요청용 짧은 문장

## 검증/주의사항
- 계산 실수 여부를 반드시 사람이 검산해야 한다
- 참석 기준이 애매하면 먼저 정산 규칙을 정해야 한다

## 관련 자산
- 문자 부드럽게 다듬기
- 공공서비스 기본 프롬프트
- AI는 정리 도구이지 판정자가 아니다

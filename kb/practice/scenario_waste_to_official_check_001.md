# 분리배출 판별에서 공식 확인까지

## 요약
헷갈리는 물건을 AI로 먼저 분류하고, 공식 기준으로 다시 확인하는 전체 흐름을 정리한 시나리오다.

## 강의 활용
- 생활 분리배출 실습 흐름
- 스마트폰 사진 활용 수업

## 세부 내용
### 흐름
1. 물건 사진을 찍거나 이름을 적는다.
2. AI에게 분리배출 종류를 먼저 묻는다.
3. 씻기, 라벨 제거, 내용물 비우기 등을 확인한다.
4. 공식 안내로 다시 검증한다.
5. 자주 헷갈리는 품목 목록을 만든다.

### 기대 결과
- 분류 결과
- 사전 준비 체크리스트
- 공식 확인 항목

## 검증/주의사항
- 지역별 기준 차이가 있을 수 있다
- 오염 상태나 예외 품목은 공식 확인이 필요하다

## 관련 자산
- 분리배출 판별하기
- 음식물쓰레기 구분하기
- 쓰레기 분리배출 프롬프트

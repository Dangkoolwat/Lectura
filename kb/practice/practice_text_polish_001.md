# 문자 부드럽게 다듬기

## 요약
거절, 사과, 부탁, 공지, 민원 같은 문장을 상황에 맞게 다듬는 실습이다.  
관계에 따라 말투를 조정하는 연습에 좋다.

## 강의 활용
- 문자/카톡 실습
- 관계 맥락 설명 연습
- 말투 조정 실습

## 세부 내용
### 실습 목표
같은 내용이라도 상대와 목적에 따라 표현이 달라져야 함을 이해하고, 문장을 여러 버전으로 바꿔 본다.

### 준비물
- 바꾸고 싶은 문자 초안
- 상대와의 관계 설명
- 스마트폰 또는 컴퓨터

### 진행 순서
1. 원문을 입력한다.
2. 상대와 상황을 설명한다.
3. 정중한 버전, 자연스러운 버전, 짧은 버전을 요청한다.
4. 보낼 문장을 선택한다.
5. 너무 딱딱하거나 과한 표현을 다시 조정한다.

### 결과물
- 상황별 문자 2~3종
- 정중한 버전
- 자연스러운 버전
- 짧은 버전

## 검증/주의사항
- 감정이 큰 상태에서는 바로 보내지 말고 한 번 더 읽어야 한다
- 관계와 상황에 맞는지 확인해야 한다

## 관련 자산
- 생활불편 민원 프롬프트
- 공공서비스 기본 프롬프트
- AI는 정리 도구이지 판정자가 아니다

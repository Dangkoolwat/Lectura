# 생성 결과물 저장 및 다듬기 팁

AI가 만들어준 초안 결과물(여행 계획서 등)은 채팅창에만 두지 말고, 수정과 공유가 쉬운 문서 형태로 저장해야 합니다.

## 1. 프롬프트로 문서 포맷 변환하기
> "지금까지 만든 여행 계획서를 인쇄하기 좋도록 A4 크기의 '여행 가이드북' 형태로 깔끔하게 정리해 줘."

## 2. HTML 페이지로 바로 출력하기
> "어르신이 보시기 좋게 글씨를 크고 명확하게 해서 깔끔한 HTML 문서 코드로 만들어 줘. 맨 위에는 '지금 바로 인쇄하기' 버튼을 넣어서 브라우저에서 바로 인쇄할 수 있게 해."

## 3. 전용 에디터(Canvas 등) 기능 활용
Gemini의 Canvas나 ChatGPT의 Canvas 기능을 활용하면, 채팅창 옆에 별도의 문서 에디터가 열립니다. 대화를 나누는 동시에 우측 문서의 특정 문단만 블록 지정하여 내용을 수정하거나 길이를 조절할 수 있습니다.
> "이번 여행 계획서를 Canvas에서 보기 좋게 정리할 수 있도록 문서 형태로 다시 구성해 줘."

## 4. 대화가 너무 길어졌을 때의 요약
수정이 많아져 대화가 길어지면 AI가 초기 조건(기준표)을 잊어버릴 수 있습니다. 이때는 기준을 다시 잡아줍니다.
> "지금까지 대화 내용을 핵심 요약해서, 새 창에서 이어서 작업할 수 있는 마스터 프롬프트로 정리해 줘. (확정 조건, 제외 조건, 미정 항목 포함)"

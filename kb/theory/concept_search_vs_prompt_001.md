# 검색과 질문(프롬프트)의 차이

AI를 기존의 포털 검색창처럼 대하면 좋은 결과를 얻을 수 없습니다. 같은 궁금증이라도 접근 방식이 완전히 달라야 합니다.

## 🔍 일반 검색 방식
- **특징**: 키워드 중심
- **과정**: 정답 후보가 있는 웹페이지를 찾아주고, 사용자가 직접 여러 페이지를 들어가 비교하고 요약해야 합니다.
- **목적**: 정보의 존재 확인 및 수집

## 💬 AI 질문 (프롬프트) 방식
- **특징**: 작업을 통째로 맡기는 방식
- **과정**: 판단에 필요한 단서(상황 설명, 조건, 기준)와 원하는 결과물의 형식(표, 요약 등)을 제시하면 AI가 분석하고 초안을 직접 만들어냅니다.
- **목적**: 생각의 자동화 및 결과물 생성

> **핵심 원칙**: AI에게는 단순한 검색어(단어)를 던지는 것이 아니라, 판단과 창작에 필요한 '구체적인 단서와 맥락'을 주어야 합니다.

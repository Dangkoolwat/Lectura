# Step-back Prompting (한 걸음 물러나서 생각하기)

## 개념
복잡한 문제일수록 바로 해결책을 묻기보다, 큰 흐름과 기본 원인, 배경 개념, 판단 기준을 먼저 정리하게 한 뒤 접근하는 프롬프트 기법입니다. 여러 관점에서 생각하고 비교하며 더 나은 답을 찾는 데 유용합니다.

## 활용 상황
- 보고서 방향 잡기
- 복잡한 개념 설명
- 문제의 원인 분석

## 프롬프트 예시
> "답하기 전에 이 문제의 핵심 개념과 원인을 먼저 정리해 줘. 그다음 해결 방향을 제안해 줘."

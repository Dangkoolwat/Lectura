# 문서용 프롬프트 vs 이미지 생성 프롬프트

글을 쓰는 AI(문서)와 그림을 그리는 AI(이미지)는 지시를 받아들이는 방식이 완전히 다릅니다.

## 문서용 프롬프트 (무엇을 자세히 정리할까?)
- **특징**: "읽는 결과물"을 만듭니다.
- **방식**: 내용을 충분히 설명하고, 세부 조건을 촘촘히 넣어도 괜찮습니다. 표, 문장, 체크리스트 형태가 중심이 됩니다.

## 이미지 생성 프롬프트 (무엇을 어떻게 보여줄까?)
- **특징**: "한눈에 보는 결과물"을 만듭니다.
- **방식**: 문서의 정보를 그대로 복붙하면 안 됩니다. 보여줄 핵심 정보만 골라 극단적으로 줄이고, '비율, 배치, 시각 요소, 분위기'를 묘사하는 데 집중해야 합니다. 텍스트가 많으면 이미지가 심하게 뭉개지거나 복잡해집니다.

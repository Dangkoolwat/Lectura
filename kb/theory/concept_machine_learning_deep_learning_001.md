# 머신러닝과 딥러닝의 부상

## 1. 머신러닝 (Machine Learning)
- **개념 전환**: 사람이 규칙을 일일이 만들어 기계에 입력하던 방식(계산의 시대)에서 벗어나, 데이터(교과서와 문제집)를 주면 기계 스스로 패턴과 규칙을 학습하는 시대로의 전환점입니다.
- **방식**: 입력 데이터(고양이 이미지)와 정답(이것은 고양이)을 주면, 모델이 이를 학습해 처음 보는 입력에도 결과를 예측합니다.

## 2. 딥러닝 (Deep Learning)
- **개념 확장**: 머신러닝 중에서도 사람의 뇌 연결 방식(인공신경망)에서 영감을 받아, 층을 아주 깊게(Deep) 쌓아 복잡한 패턴을 학습하는 기술입니다.
- **영향**: 딥러닝의 폭발(2012년 AlexNet) 이후 AI는 단순한 숫자나 정형 데이터를 넘어 이미지, 언어, 음성 등 여러 어려운 대상을 판단하고 생성하는 분야로 크게 확장되었습니다.
